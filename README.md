## Integrating The  Biggest ModPAck+External

This pack exposes a supported API for other plugins — content registration plus behaviour hooks
(inventory/equipment providers, sacrifice filters, lifecycle events, loot generation). 


## 🛠️ Installation Guide

Follow these steps to install DeltaMod:

### 1. Download the Archive

Download the **`Valheim_ModPack`** archive from the download link above.

### 2. Extract the Archive

Right-click the downloaded archive and select **Extract All...**. Choose a folder where you want to extract the files. Windows supports extracting ZIP archives directly through File Explorer.

### 3. Run the Installer

Open the extracted folder and locate:

```text
External_Setup.exe
```

Double-click **`External_Setup.exe`** to start the installation.

### 4. Complete the Installation

Follow the instructions shown by the installer and wait for the installation to finish.

> **⚠️ Important:** Only run `External_Setup.exe` if you obtained the archive from a source you trust. Windows executable files can launch programs on your system.
